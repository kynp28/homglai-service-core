1. ภาพรวมโครงสร้างเอนทิตี (Entity Overview)

ระบบฐานข้อมูลประกอบด้วย 9 เอนทิตีหลัก ซึ่งแบ่งตามขอบเขตการทำงานของระบบ (Domain Boundaries) ออกเป็น 5 กลุ่มงานสำคัญ ดังต่อไปนี้:

กลุ่มงาน เอนทิตี (Model) บทบาทและหน้าที่ในกระบวนการทางธุรกิจ
1. บุคลากรและลูกค้า Employee จัดการข้อมูลพนักงานและช่างซ่อม รองรับระบบคิวสถานะการทำงาน และการจัดเก็บ LINE User ID สำหรับแจ้งเตือนการจ่ายงาน
Customer จัดการข้อมูลลูกค้าผู้ส่งซ่อม หมายเลขโทรศัพท์ระบุตัวตน และ LINE User ID สำหรับการติดตามสถานะงานซ่อมแบบเรียลไทม์
2. ข้อมูลหลัก (Master Data) SymptomCategory จัดหมวดหมู่อาการเสียมาตรฐานของเครื่องชงกาแฟ (เช่น ระบบน้ำ, ระบบไฟฟ้า, ระบบความร้อน)
Symptom รายการอาการเสียมาตรฐานที่ผูกกับหมวดหมู่ สำหรับให้ฝ่ายต้อนรับเลือกประเมินสภาพเครื่องเบื้องต้น
3. ทรัพย์สินและงานซ่อมหลัก Machine จัดการข้อมูลเครื่องชงกาแฟที่เข้ารับบริการ ผูกโยงกับเจ้าของเครื่อง ยี่ห้อ รุ่น และหมายเลขประจำเครื่อง (Serial Number)
RepairOrder เอนทิตีแกนกลางของระบบ จัดเก็บข้อมูลใบรับซ่อม รหัสงาน (Job Number), สถานะงานซ่อม, และช่างเทคนิคผู้รับผิดชอบ
RepairOrderSymptom ตารางเชื่อมโยง (Junction Table) สำหรับความสัมพันธ์แบบกลุ่มต่อกลุ่ม (Many-to-Many) ระหว่างใบสั่งซ่อมและอาการเสียที่ตรวจพบ
4. การเสนอราคาและอนุมัติ RepairItem จัดการรายการอะไหล่หรือค่าบริการซ่อมเพิ่มเติม พร้อมวงจรสถานะการอนุมัติรายชิ้นจากลูกค้า (Itemized Approvals)
5. การตรวจสอบและประวัติ StatusLog บันทึกประวัติการเปลี่ยนสถานะของใบสั่งซ่อม (Audit Trail) พร้อมระบุพนักงานผู้ดำเนินการและหมายเหตุประกอบ

2. แผนภาพความสัมพันธ์ของข้อมูล (Data Relationships)

2.1 ความสัมพันธ์แบบหนึ่งต่อกลุ่ม (One-to-Many Relationships)

เอนทิตีหลัก (1) เอนทิตีรอง (Many) คำอธิบายความสัมพันธ์
Customer Machine ลูกค้า 1 ราย สามารถลงทะเบียนเครื่องชงกาแฟในระบบได้มากกว่า 1 เครื่อง
Customer RepairOrder ลูกค้า 1 ราย สามารถเปิดใบสั่งซ่อมได้หลายรายการตลอดอายุการใช้งาน
Machine RepairOrder เครื่องชงกาแฟ 1 เครื่อง สามารถมีประวัติการเข้าซ่อมบำรุงได้หลายครั้ง
Employee (AssignedTechnician) RepairOrder ช่าง 1 คน สามารถได้รับมอบหมายใบสั่งซ่อมได้หลายใบ (ค่าเป็น Nullable เมื่ออยู่ในคิวรอมอบหมาย)
Employee StatusLog พนักงาน 1 คน สามารถเป็นผู้บันทึกประวัติการเปลี่ยนสถานะของใบสั่งซ่อมได้หลายรายการ
RepairOrder StatusLog ใบสั่งซ่อม 1 ใบ จัดเก็บประวัติการเปลี่ยนสถานะตลอดขั้นตอนการดำเนินงานได้หลายรายการ
RepairOrder RepairItem ใบสั่งซ่อม 1 ใบ สามารถมีรายการประเมินค่าซ่อมหรืออะไหล่ที่ต้องเสนอราคาได้หลายรายการ
SymptomCategory Symptom หมวดหมู่อาการเสีย 1 หมวด ครอบคลุมรายการอาการเสียย่อยมาตรฐานได้หลายรายการ

2.2 ความสัมพันธ์แบบกลุ่มต่อกลุ่ม (Many-to-Many Relationship)

ความสัมพันธ์ระหว่าง RepairOrder และ Symptom เชื่อมโยงผ่านโมเดล RepairOrderSymptom โดยใช้คีย์หลักแบบผสม (Composite Primary Key: [repairOrderId, symptomId]):

  • ใบสั่งซ่อม 1 ใบ สามารถระบุอาการเสียเริ่มต้นได้หลายอาการพร้อมกัน
  • อาการเสียมาตรฐาน 1 รายการ สามารถปรากฏอยู่ในใบสั่งซ่อมหลายใบได้

4. ค่าคงที่และแจงนับ (Enums & Constants)

EmployeeRole ENUM
กำหนดระดับสิทธิ์และการแบ่งหน้าที่การทำงานในระบบ
  • ADMIN : ผู้ดูแลระบบ มีสิทธิ์เข้าถึงและจัดการข้อมูลทั้งหมด
  • TECHNICIAN : ช่างเทคนิค ผู้รับผิดชอบการตรวจสอบ ซ่อมแซม และเสนอราคาอะไหล่
  • RECEPTIONIST : ฝ่ายต้อนรับ รับผิดชอบการเปิดใบรับซ่อม (Intake) และประสานงานลูกค้า
EmployeeStatus ENUM
ใช้สำหรับกลไกจัดสรรคิวงานซ่อมอัตโนมัติ (Queue Management)
  • AVAILABLE : ว่าง พร้อมรับงานซ่อมใหม่จากระบบคิวอัตโนมัติ
  • BUSY : กำลังปฏิบัติงานซ่อม ไม่พร้อมรับงานใหม่
  • OFFLINE : ลางาน หรืออยู่นอกเวลาทำการ
RepairStatus ENUM
ควบคุมขั้นตอนการดำเนินงานซ่อมตั้งแต่เปิดใบงานจนส่งมอบ
  • NEW : รับเครื่องเข้าสู่ระบบเรียบร้อย รอจัดสรรคิวให้ช่าง
  • INSPECTING : ช่างกำลังดำเนินการตรวจสอบเครื่องและประเมินสภาพ
  • WAITING_APPROVAL : รอลูกค้าพิจารณาอนุมัติรายการซ่อมหรือค่าใช้จ่ายเพิ่มเติม
  • REPAIRING : กำลังดำเนินการซ่อมหรือเปลี่ยนอะไหล่ตามที่ได้รับอนุมัติ
  • COMPLETED : การซ่อมเสร็จสิ้น เครื่องผ่านการทดสอบพร้อมส่งคืน
  • DELIVERED : ส่งมอบเครื่องคืนให้ลูกค้าเรียบร้อยแล้ว
  • CANCELLED : ยกเลิกรายการซ่อม
ItemStatus ENUM
ควบคุมการตัดสินใจของลูกค้าต่อรายการอะไหล่แต่ละชิ้น (Approval Loop)
  • PENDING : รอการพิจารณาอนุมัติจากลูกค้า
  • APPROVED : ลูกค้ายืนยันการซ่อมหรือเปลี่ยนอะไหล่ชิ้นนี้
  • REJECTED : ลูกค้าปฏิเสธการซ่อมรายการนี้
  • COMPLETED : ช่างดำเนินการเปลี่ยนหรือติดตั้งอะไหล่รายการนี้เสร็จสิ้น
